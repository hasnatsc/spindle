GL Account Defaults

When a booking is confirmed, Spindle looks up Travel Revenue Account here first. If it's not set, it falls back to any active REVENUE account whose code starts with TRAVEL, then to any active REVENUE account. Confirming a booking will fail if none exist.

Payment Mode → Account Mapping

Map each payment mode to a default sub-account (GL head). When a receipt is created, the DR side uses this sub-account's main account. If no mapping is set, the user must select a sub-account manually on the booking receipt line.
